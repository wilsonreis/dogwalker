# Débora Araújo — Passeios com propósito

Landing page mobile-first para apresentar os passeios e o trabalho de Débora Araújo dos Reis, bióloga com experiência relacionada a cães e gatos, em Campos dos Goytacazes, RJ.

## Executar localmente

Abra `index.html` no navegador. O projeto usa HTML, CSS e JavaScript sem dependências ou etapa de build.

## Personalização

- As imagens e fontes são carregadas de serviços externos (Unsplash e Google Fonts).
- O formulário monta uma mensagem e abre o WhatsApp. Para direcionar ao número profissional, edite `script.js` e substitua `https://wa.me/` pelo endereço com o número no formato internacional, por exemplo `https://wa.me/5522999999999`.
- Atualize o conteúdo e as regiões atendidas em `index.html` conforme necessário.
